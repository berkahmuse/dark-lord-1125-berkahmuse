Entry for the [make.fun bounty "The Tired Dark Lord: A 100-Word Villain Monologue"](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb).

A deterministic program (`main.ts`, Node 22) that writes a ~100-word monologue to `/output/entry.txt` — spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the voice, the rhythm and the small deflections (trailing thoughts, a lost thread, a pause mid-scheme), never in a plain statement of weariness. The speaker is still a villain: three centuries into collecting the bell of Vharra, one dawn and one locked door at a time.

## Run

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Two runs produce byte-identical output.
